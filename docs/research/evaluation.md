# Evaluation Protocol

更新：2026-09-17。以下为从前期对话提炼并澄清的实验协议草案；尚未实现或冻结具体阈值、掩码与窗口。当前 Target=VIL(t)，Lead Time=0 min。

## 比较前置条件

记录 dataset 版本、event 列表、训练/验证/测试划分、输入模态与时间窗、Target 定义/单位、重采样、网格、掩码、归一化、loss、随机种子、训练预算和后处理。只有这些一致或差异被控制时才比较数值。原始 1 km SEVIR 与项目 2 km Target 分开报告。

指标在反归一化后计算，注明编码值或物理值。无效值不当作无回波。空分母返回 NA 并记录有效样本数，不能默认为完美分数。事件级不确定区间以 event/storm 重采样，不能把高度相关像元视作独立样本。

## 连续值与图像指标

设 e=预测−观测，对共同有效像元求统计。

| Metric | 定义/含义 | 本任务价值与局限 |
|---|---|---|
| MAE | mean(abs(e)) | 数值偏差、相对稳健；大量弱值可掩盖强核错误 |
| MSE / RMSE | mean(e²) / sqrt(MSE) | 大误差惩罚强；对位移有双重惩罚，不等于结构正确 |
| Mean Bias | mean(e) | 总体高估/低估；正负误差会抵消 |
| Pearson r | 线性相关 | 共变是否正确；比例和幅度错误仍可能相关高 |
| PSNR | 10 log10(L²/MSE)，L 是固定数据范围 | 图像误差参照；必须给 L 和单位，不能逐图选最大值 |
| SSIM / MS-SSIM | 局地亮度、对比和结构相似性 | 辅助形态评价；须固定范围、窗口，不能解释为降水质量 |
| LPIPS | 感知特征距离 | 可追踪 SEVIR 感知损失效果；不是物理指标，通常越低越好 |

SEVIR Table 2 对比同一 synrad 协议的 MSE、MSE+content、cGAN+MAE，显示感知与高阈值事件指标不必同向。复现时引用该表而非 nowcasting 图表。[SEVIR 原文](https://proceedings.neurips.cc/paper/2020/file/fa78a16157fed00d7a80515818432169-Paper.pdf)

## 阈值气象指标

针对预先固定阈值 q 二值化。H=命中，M=漏报，F=虚警，C=正确拒绝，N=H+M+F+C。

| Metric | 公式 | 解读和不平衡问题 |
|---|---|---|
| POD / Recall | H/(H+M) | 实际事件被检出比例；扩大预测区域可提高 POD，必须同时报告 FAR |
| FAR（false alarm ratio） | F/(H+F) | 预测事件中错误比例；不是 false positive rate F/(F+C) |
| Precision / Success Ratio | H/(H+F)=1−FAR | 检出可信度；与事件发生率相关 |
| CSI | H/(H+M+F) | 排除大量正确无事件像元；稀有高阈值仍很难且受发生率影响 |
| Frequency Bias | (H+F)/(H+M) | 理想值 1；说明事件面积频率，不衡量位置准确性 |
| ETS | (H−Hr)/(H+M+F−Hr)，Hr=(H+M)(H+F)/N | 扣除随机命中；稀有事件样本少时不稳定 |
| HSS | 2(HC−FM)/[(H+M)(M+C)+(H+F)(F+C)] | 相对随机分类技巧；需连同列联表与发生率解释 |

不得使用总体 accuracy 代替稀有事件技巧。除全测试集累计 H/M/F 外，报告按事件分布和有效事件数；宏平均与累计后计算不是同一量。

官方 SEVIR 编码阈值为 **16、74、133、160、181、219**；这是 benchmark 编码阈值，不是 kg/m² 数字。解码和粗化后若使用物理阈值，应明确转换/重新定义；测试集 P99 不可用来事后挑选阈值。高 VIL 标签应称“超阈值核心”，除非另有证据支持气象灾害等级。[SEVIR §3.2](https://proceedings.neurips.cc/paper/2020/file/fa78a16157fed00d7a80515818432169-Paper.pdf)

## 空间结构、分布和极端

| 评价层 | 建议输出 | 要回答的问题 |
|---|---|---|
| FSS | 每个 q、每个邻域尺度的分数曲线 | 强核略有位移还是系统整体结构错误 |
| 对象/连通域 | 个数、面积、形状、质心和峰值位置误差；固定匹配规则 | 检出的是正确核心，还是虚构/错位核心 |
| 分布 | 直方图、P90/P95/P99/P99.5、最大值与频率 | 是否压低尾部或制造过多极值 |
| 条件误差 | 真实值超训练集 P95/P99 时的 MAE/Bias，分段报告 | 全场低误差是否隐藏高值失败 |
| 昼夜/区域/季节 | 共同子集的指标与样本数 | C02 收益、地理和天气型泛化 |
| 连续案例 | 逐帧核心轨迹、面积与强度曲线，必要时定义时间差误差 | 当前时刻输出是否不合理闪烁；不改变 lead=0 任务 |

FSS 使用邻域内超阈值比例 pf、po：`1 − mean((pf−po)²)/(mean(pf²)+mean(po²))`。须固定边界/缺测处理。建议先用 **窗口边长** w=1、3、5、9 像元，在 2 km 网格为 2、6、10、18 km；这只是待冻结的项目方案。前期对话的 `r=1,2,4,8 → 2,4,8,16 km` 未区分半径与边长，不能直接照抄为实现规格。若使用半径 r，边长应为 2r+1。

Hu 等提供了结构技巧与像素误差可能分离的直接领域实例，但目标为反射率，其绝对 FSS 数值不可当作本项目合格线。[论文](https://doi.org/10.1175/AIES-D-25-0016.1)

## 生成式 / 概率模型的额外要求

- CRPS：同时评价集合分布与实测值偏差；记录成员数和估计公式。
- Brier Score：各 VIL 阈值超越概率的平方误差；配合 reliability diagram、样本数和参考气候概率。
- Rank histogram、覆盖率、spread-skill：检查欠离散/过离散与校准；不能仅展示好看的成员。
- 确定性评分分别报告 ensemble mean、固定成员或预先指定汇总方式；禁止从集合中根据真值挑 best-of-N 当主结果。
- 集合均值可能再次变平滑，成员锐利度、概率质量与均值误差应分别呈现。记录推理步数、成员数、硬件、耗时与显存。

SRDiff 仓库列有 CSI/POD/SR/Bias/HSS/SSIM/CRPS；其公开版本明确 FVD 为 NaN，缺完整 detector/protocol，不能将其描述为已支持完整 FVD 复现。[官方仓库](https://github.com/42xingxing/SRDiff)

## 最小结果包

总体 MAE/RMSE/Mean Bias + 多阈值 CSI/POD/FAR/Frequency Bias + 多尺度 FSS + 高值尾部/核心指标 + 同范围典型/失败个例 + 按事件置信区间。生成模型另加 CRPS、Brier 与可靠性。每份结果同时保存配置、划分、模型版本和指标实现版本；不能只保存彩图和一个平均分数。
