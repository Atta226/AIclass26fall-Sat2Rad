# 数据工程契约

本目录将保存面向可执行代码的 SEVIR Benchmark 数据工程契约；它与研究层面的数据集分析刻意分离。

未来契约将覆盖：

- 规范样本标识与来源追踪；
- 变量、目标、掩膜、时间和空间语义；
- 数据划分协议与清单要求；
- 数值域和单位转换；
- 数据产物与版本管理规则。

科研动机、科学局限和预处理方案比较仍放在 [docs/research/datasets.md](../research/datasets.md)。本目录当前并未定义可运行的 Dataset 或 DataLoader。

## 当前状态

尚未冻结任何数据工程契约。只有在根据真实 SEVIR 文件、目录字段、编码方式和对齐假设完成核验后，才会建立首个契约。
